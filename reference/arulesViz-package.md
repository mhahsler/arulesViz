# arulesViz: Visualizing Association Rules and Frequent Itemsets

Extends package 'arules' with various visualization techniques for
association rules and itemsets. The package also includes several
interactive visualizations for rule exploration. Michael Hahsler (2017)
[doi:10.32614/RJ-2017-047](https://doi.org/10.32614/RJ-2017-047) .

## Main Functions

- [`plot()`](http://michael.hahsler.net/arulesViz/reference/plot_arulesViz.md)
  plot association rules.

- [`inspectDT()`](http://michael.hahsler.net/arulesViz/reference/inspectDT.md)
  for interactive rule tables.

- [`ruleExplorer()`](http://michael.hahsler.net/arulesViz/reference/ruleExplorer.md)
  for interactive rule inspection with tables and graphs.
